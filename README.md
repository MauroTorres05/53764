# Analizador Léxico, Sintáctico e Intérprete JS-Subset

Este repositorio contiene la entrega del analizador basado en un sub-lenguaje de JavaScript utilizando **Node.js** y **ANTLR4**.

## Requisitos Previos
- Instalar [Node.js](https://nodejs.org/).
- Extension de ANTLR4 instalada en Visual Studio Code.

## Pasos para la ejecución

1. Clonar el repositorio localmente.
2. Abrir la terminal y ubicarse dentro de la carpeta `analizador`:

   cd analizador
   npm install
